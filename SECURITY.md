# Security Policy

## Supported Versions

Security fixes are accepted for the current `main` branch.

## Reporting a Vulnerability

Please do not file public issues for vulnerabilities. Email the maintainers or use a private security advisory if the repository host supports it.

Include:

- A description of the issue and affected commands.
- Reproduction steps.
- Any local project files required to reproduce, with secrets removed.

## Scope

Godot MCP can read and write files inside the connected Godot project and can control parts of the Godot editor. Only enable the plugin for projects and MCP clients you trust.
